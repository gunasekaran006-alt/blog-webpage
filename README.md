# Acela - Modern Blog Webpage

A professional, fully responsive front-end blog webpage layout. This project demonstrates the effective use of **CSS Flexbox** for creating dynamic grids and structured layouts.

## ✨ Features
* **Fully Responsive:** Adapts seamlessly to desktops, tablets, and mobile devices using CSS Media Queries.
* **Flexbox Powered:** Utilizes modern Flexbox techniques for the navigation bar, featured post section, and blog grid.
* **Interactive UI:** Includes hover effects on blog cards and stylized buttons for better user engagement.
* **Clean Code:** Structured with semantic HTML5 for better accessibility and SEO.

## 🛠️ Tech Stack
* **HTML5:** For content structuring.
* **CSS3:** For custom styling, Flexbox layout, and responsiveness.
* **Google Fonts / System Fonts:** For professional typography.
